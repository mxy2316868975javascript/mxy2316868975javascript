# Publish This Profile

1. Create a new public repository named `mxy2316868975javascript` under the `mxy2316868975javascript` account.
2. Copy the contents of this directory into that repository and push them to its default `main` branch.
3. In the repository settings, set **Actions > General > Workflow permissions** to **Read and write permissions**.
4. Run **Generate contribution flow** once from the Actions tab. It creates the `output` branch used by the animated contribution graph.
5. Pin public repositories from the profile overview after they are ready to show.

The profile repository name must exactly match the GitHub username; GitHub then renders its `README.md` at the top of the profile page.
